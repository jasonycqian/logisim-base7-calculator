# Base-7 Digital Logic Calculator

A 7-segment, septenary (Base-7) calculator schematic built using **Logisim Evolution**. This project demonstrates custom digital logic design, modulo arithmetic, gate-level ALU implementation, and display decoding logic.

---

## 📌 Features & Architecture

* **Custom ALU:** Performs Base-7 addition and subtraction, equipped with status flags for overflow and zero states.
* **Septenary Decoding:** Custom control logic and decoders designed to translate 3-bit binary/septenary outputs directly onto simulated 7-segment displays.
* **Control Pathways & Registers:** Gate-level registers and multiplexers for routing operand inputs and arithmetic outputs.
* **Modular Logic:** Built entirely with fundamental logic gates, adders, decoders, and multiplexers in Logisim.

---

## 🛠️ Built With

* **Simulation Tool:** Logisim Evolution
* **Logic Type:** Gate-level digital logic, combinational & sequential circuits
* **Radix System:** Base-7 (Septenary)
